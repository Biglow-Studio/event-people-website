## Where submissions are emailed

Every submission is saved in Webflow and emailed to **fulvia@eventpeople.us**. Two settings
control that, and the form's own setting wins over the site default:

- **Site default:** Site settings → **Forms** → **Send form submissions to**. Set to
  fulvia@eventpeople.us on September 29, 2026 (it still pointed at the original developer).
- **The Contact Form itself:** in the Designer, select the form block → **Settings** → **Send to** →
  **Email Notifications**. It follows the site default. Until September 29, 2026 it had its own
  recipient (the original developer) and ignored the site setting; **Reset to defaults** in that
  popover cleared it. If someone adds a recipient here again, only that address gets the email.

<Warning>
  The staging address sends the same emails, so a test submission on
  event-people-reworked.webflow.io lands in Fulvia's inbox.
</Warning>

After sending, the form shows **"Thank you for your submission!"** in black on the white card (the
`form-success_flex` class uses the **Neutral / Black** colour; it used to carry `u-text-white`, which
made the message invisible on the white card). Preview it in the Designer with the form block's
**State → Success**.

## "Where did you find us?"

A Select Field with the choices **LinkedIn · Google · An AI engine · YouTube · Instagram · Other**,
followed by an optional text field (**If other, please tell us where**) that only appears when
**Other** is picked.

<Note>
  The show/hide toggle is **not** in this repo. It lives in the Contact page's own custom code —
  Webflow: page settings → **Before `</body>` tag**. It's a handful of lines that match the select
  `#Where-Did-You-Find-Us` to the input `#Where-Did-You-Find-Us-Other` and hide that input's
  `.input-group` unless the value is `Other`. It was kept page-level so the site-wide script tag
  didn't need a new jsDelivr version for one page's form — see [Hosting the Custom Code](/custom-code/hosting).
</Note>

To change the choices: select the dropdown on the canvas, then **Settings → Select Field settings →
Choices**. Set both **Text** and **Value** on each choice, and keep an option whose value is exactly
`Other`, or the extra text field will never appear.

## Recommended workflow

- Check submissions on a regular cadence.
- Reply to the person in your email client — do not reply from Webflow.
- Save important leads into your CRM.

## Automation opportunity

- Route form submissions to a tool of your choosing (Mailchimp, HubSpot, Salesforce, etc.) depending on your outbound goals.
- From there, set up a validation flow that prompts signed-up users to confirm their email so your communications reach their inbox.
