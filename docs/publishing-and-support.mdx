## Publishing, backups, and rollback

Depending on permissions, content editors can publish:

- Individual CMS items.
- To the Webflow staging domain (`webflow.io`).
- To the production domain.

Webflow publishes can be immediate. Before you publish:

- Confirm you are publishing to the correct domain.
- If the change is significant, capture a quick before/after screenshot.

If something breaks:

- Revert the content change if possible.
- If it was a layout/code change, pause publishing and request support.
- If a new custom-code release caused it, point the script URLs back at the previous tag and republish — see [Hosting the Custom Code](/custom-code/hosting#shipping-a-change-to-a-js-file).
