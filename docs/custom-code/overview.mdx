Custom code here is JavaScript layered on top of Webflow's standard build — almost entirely GSAP-driven scroll and interaction animation (sliders, pinned sections, split-text reveals, etc.), plus one smooth-scroll library.

<Note>
  **Current state:** the three live files are wired into Webflow and served from jsDelivr, each pinned to a repo tag — `global.js` site-wide via the site footer code (`v1.0.0`), `home.js` on Home (`v1.0.0`), and `how-we-work.js` on European Hubs and New York (`v1.4.0`). Contact has a small page-level script for the "If other" form field, and Home, European Hubs, New York and About carry page-level CSS (see [Page-level CSS](#page-level-css)). Pushing to `main` alone doesn't change the live site — see [Hosting the Custom Code](/custom-code/hosting) for the exact snippets and how to ship a change.
</Note>

## The four project files

<Info>
  **Last reconciled with the Webflow site in September 2026**, after the European Hubs / New York restructure. Webflow structure can drift from the code without warning — re-check before changing either side if it's been a while.
</Info>

| File | Scope | What it drives |
|---|---|---|
| [`global.js`](https://github.com/Biglow-Studio/event-people-website/blob/main/global.js) | **Site-wide** | Nav menu open/close animation and content stagger; hides the nav bar once the footer scrolls into view. Loaded from the site footer code, so it runs on every page. |
| [`home.js`](https://github.com/Biglow-Studio/event-people-website/blob/main/home.js) | **Home** page only | Cascading image slider, sticky steps indicator, hero video object-position handling. |
| [`about.js`](https://github.com/Biglow-Studio/event-people-website/blob/main/about.js) | **Deprecated — not in use** | Built for an earlier About page layout: a pinned visuals column against a step timeline, plus an interactive image collage. The current About Us page doesn't use any of that markup, so this file will not be wired in. Kept in the repo for reference only — see [Hosting the Custom Code](/custom-code/hosting). |
| [`how-we-work.js`](https://github.com/Biglow-Studio/event-people-website/blob/main/how-we-work.js) | **European Hubs** + **New York** pages | Drives the "how we work" sticky-video scroll reveal on **both** European Hubs and New York. Items hidden in Webflow (`display: none`) are skipped — a hidden item used to leave dead scroll at the end of the pinned section — and since `v1.3.0` each line fully leaves before the next one arrives (no overlap), the first and last lines hold still at the start and end of the pinned section, and if you stop scrolling partway through a change it glides (through Lenis) on to the next line in the direction you were scrolling, so it never rests mid-change. Since `v1.2.0` it also builds the **European Hubs representatives slider** (`initRepSliders`): any `.collective-gsap-slider` with a `data-rep-slider` attribute is rebuilt from its CMS cards as the Home-style cascading slider (same `.cascading-slider*` classes as `home.js`, no autoplay). Since `v1.4.0` the active slide is a portrait frame (4:5 on tablet and desktop, taller on phones) sized from the window, the person's role, country and bio sit on the photo under their name, and there is no panel, counter or arrow buttons: visitors click a neighbouring photo, swipe, or use the arrow keys. The file still contains the spatial member-card slider (`initSpatialCardsSlider`) and bio "read more" toggle (`initCollectiveCardBios`), but both are inert: there's no `data-spatial-slider-init` attribute or `.read-more-button` in the markup, so both return early. A third feature that used to live here — a radial cards slider — was removed from the live site; only orphaned CSS referencing it remains, and the corresponding JS has been cleaned out of this file. |

<Warning>
  **Do not delete or edit custom code unless you are explicitly instructed to.** These files are tightly coupled to specific class names and data attributes in the Webflow structure — small changes on either side (Webflow structure or the JS) can silently break animations.
</Warning>

## Page-level CSS

Some layout lives in each page's **Page settings → Custom code → Inside `<head>`** rather than in
Webflow classes. Page custom code doesn't render in the Designer canvas, so these sections look
plainer in the Designer than on the live site.

| Page | What the page CSS does |
|---|---|
| Home | One section padding between the "Corporate events…" paragraph and the list under it, and a little room under the list so its last row's descenders aren't clipped. The Designer-only slider CSS above it is from the original build. |
| European Hubs | The pink banner (`.section.u-bg-primary.u-text-white`): one section padding above and below the line, inset by the page gutter, and its type size; country-card type size, the crop of the France photo, and one section padding after the last card (`[data-countries]`); all of the representatives slider's styling (`.rep-slider*`: the portrait frame and the name, role · country and bio on the photo; it also hides the original grid once the slider is built); spacing under the sticky-video intro, above the "guardian angels" paragraphs and after the last one; the n8n video credit (`.video-credit`). The older radial/spatial slider CSS above it is orphaned. |
| New York | The pink banner, as on European Hubs; spacing under the sticky-video intro; a little padding under each representative's bio (`.collective-card .bio-text-wrapper`), because the bios use trimmed text boxes and the list's overflow-hidden container was cutting off the last line's descenders. Same orphaned slider CSS as European Hubs. |
| About Us | The three rows under the intro as a checkerboard (`[data-about-split]`): each row half photo, half text with no gaps, photos alternating sides so they meet corner to corner, row titles in the display serif at the section-title size and the text at body size, centred; one section padding under the intro paragraph. The timeline marker CSS above it is left over from the hidden timeline section. |

## Site-wide layout (Webflow classes and variables)

These live in the Webflow Designer itself, not in custom code, so they show on the canvas:

- **No fixed maximum width.** The **Components → Container / Max Width** variable is `100vw`, so every container (nav, footer, content) runs the full width of the screen minus the gutter on every screen size. `.container.u-max-w-90` uses the same formula, so the containers that used to stop at 1440px follow it too.
- **One gutter.** **Components → Container/Gutter** (`0.75em`, about 12px) is the side margin for text and for the full-bleed blocks: the heroes (`.section.hero`), the sticky video and photo cards (`.minimal-card-item`), the pink banners (page CSS) and the Contact photo block (`.section.contact-us`). The © bar (`.footer-legal`) sits on it too.
- **One gap between sections.** The visible space between two sections is one **Section / Padding**: the sticky-video sections have no bottom padding (`.section.sticky-video`), the Home paragraph section has none at all (`.section.narrative-home`), and the section titles no longer sit in a `u-mt-lg` spacer. The circles (`.circles-wrapper`) have no minimum height, and their bottom padding matches their overlap.
- The gap between a section title and its content is about 47px everywhere (`.circles-wrapper` and `.collective-gsap-slider` have a `1.5rem` top margin).

## Dependencies (load order matters)

These files depend on **GSAP** and several of its plugins, loaded *before* the project files:

- Core: `gsap` 3.15 and `ScrollTrigger`, loaded site-wide by Webflow's built-in GSAP integration. Don't add `gsap.min.js` again.
- `SplitText`: site footer code, every page. `global.js` calls `gsap.registerPlugin(SplitText, ScrollTrigger)`, which is why it loads site-wide.
- `Observer`: Home page code.
- `Draggable`, `InertiaPlugin`, `CustomEase`: European Hubs and New York page code. `how-we-work.js` registers them as soon as it loads (and throws an error without them), so keep these tags even though the member-card slider that uses them is inert.

The plugins load from the `gsap@3.15` package on jsDelivr, matching the core version. Exact script tags are on [Hosting the Custom Code](/custom-code/hosting#where-each-file-needs-to-go-in-webflow).

<Info>
  GSAP's formerly paid "Club GreenSock" plugins (including SplitText and InertiaPlugin) became free for everyone following Webflow's acquisition of GreenSock, so no paid key is required. See [gsap.com](https://gsap.com) for current licensing.
</Info>

Also in the site footer code, and not part of this repo: **Lenis** smooth scrolling (`lenis@1.3.26` from unpkg), started with `new Lenis({ autoRaf: true })`. Leave this as-is unless you're deliberately replacing it.
