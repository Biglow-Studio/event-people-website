Custom code here is JavaScript layered on top of Webflow's standard build — almost entirely GSAP-driven scroll and interaction animation (sliders, pinned sections, split-text reveals, etc.), plus one smooth-scroll library.

<Warning>
  **Current state as of this handoff:** the project's custom-code files live in this repo but are **not yet wired into Webflow** — no scripts are currently registered or applied at the site or page level. The only custom code already live on the site is the Lenis smooth-scroll snippet described below. See [Hosting the Custom Code](/custom-code/hosting) to wire them in.
</Warning>

## The four project files

<Info>
  **Verified against the live staging site** (`event-people-reworked.webflow.io`) on 2026-09-08. Webflow structure can drift from the code without warning — re-check before wiring anything in if it's been a while.
</Info>

| File | Scope | What it drives |
|---|---|---|
| [`global.js`](https://github.com/tamyankevich/EP-rework/blob/main/global.js) | **Site-wide** | Nav menu open/close animation and content stagger; hides the nav bar once the footer scrolls into view. Runs on every page. Confirmed live on all pages. |
| [`home.js`](https://github.com/tamyankevich/EP-rework/blob/main/home.js) | **Home** page only | Cascading image slider, sticky steps indicator, hero video object-position handling, a hover sound effect (currently commented out/disabled in the code). |
| [`about.js`](https://github.com/tamyankevich/EP-rework/blob/main/about.js) | **Deprecated — not in use** | Built for an earlier About page layout: a pinned visuals column against a step timeline, plus an interactive image collage. The About page's current bio/text layout is the intended, permanent version going forward, so none of that markup exists and this file will not be wired in. Kept in the repo for reference only — see [Hosting the Custom Code](/custom-code/hosting). |
| [`the-collective.js`](https://github.com/tamyankevich/EP-rework/blob/main/the-collective.js) | **Destinations** + **The Collective** pages | Drives the sticky-video scroll-reveal service cards, confirmed live on **both** Destinations and The Collective (each with its own copy/framing) — despite the filename, it's not Collective-exclusive. Also drives the spatial member-card slider and bio "read more" toggle, which **are** Collective-only. A third feature that used to live here — a radial cards slider — was removed from the live site; only orphaned CSS referencing it remains, and the corresponding JS has been cleaned out of this file. |

<Warning>
  **Do not delete or edit custom code unless you are explicitly instructed to.** These files are tightly coupled to specific class names and data attributes in the Webflow structure — small changes on either side (Webflow structure or the JS) can silently break animations.
</Warning>

## Dependencies (load order matters)

These files depend on **GSAP** and several of its plugins, loaded *before* the project files:

- Core: `gsap`
- Plugins used somewhere across the four files: `ScrollTrigger`, `SplitText`, `CustomEase`, `Draggable`, `InertiaPlugin`, `Observer`

<Info>
  GSAP's previously-paid "Club GreenSock" plugins (SplitText, Draggable, InertiaPlugin, Observer, CustomEase) became free for everyone following Webflow's 2025 acquisition of GreenSock — confirm current licensing/CDN links at [gsap.com](https://gsap.com) before wiring these in, but no paid key should be required today.
</Info>

Already live and unrelated to this repo: a **Lenis** smooth-scroll script is loaded site-wide via Project Settings → Custom Code → Footer Code, pulled directly from a public CDN. Leave this as-is unless you're deliberately replacing it.
